这个页面在算什么

麦当劳的菜单里，同一批东西常常有好几种买法：单点、三件套、四件套、加购、优惠券。 单看一样差不了几块，但每次点单都会重演一次。

这个页面做一件很窄的事：拿一家门店的真实菜单快照，把同一批商品的两种买法摆在一起， 算出你多花了多少。价格来自麦当劳 MCP 的门店菜单，不是估算，也不是举例凑的。

常见的几种点法这里都能算：

  • 三十块、四十五块在麦当劳能吃到什么，怎么配最划算；
  • 在减脂或增肌，有热量和蛋白目标，忌口会被当成硬门槛直接剔除；
  • 手里一堆优惠券，想知道哪张先用、哪张注定过期；
  • 一群人吃饭，要在总预算里给一桌人配餐。

这个页面只是最直观的一段。完整的比价口径（带券实测计价、按真实点单频率排出的用券顺序） 在 GitHub 仓库 里，需要接入麦当劳 MCP 使用。

这个页面只是一家门店、一个时间点的回放。完整版会拉你常去那家店的实时菜单， 把优惠券和减脂目标一起算进去 —— 命令行一条命令就能跑，不需要 Token。
